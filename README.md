# ☕ Modern Java Recipes — Practice

**Практическое изучение Java по книге Кена Коузена «Современный Java. Рецепты программирования».**

Этот репозиторий — моя личная коллекция примеров, упражнений и экспериментов с Java.

Основная цель — не просто прочитать книгу, а закрепить полученные знания на практике, разобраться в возможностях языка и научиться применять их самостоятельно.

## 📁 Структура проекта

Исходный код находится в `src/main/java`.

Каждая глава книги представлена отдельным Java-пакетом:

- `chapter01` — основы Java 8
- `chapter02` — функциональные интерфейсы
- `chapter03` — Stream API
- `chapter04` — Comparators и Collectors
- `chapter05` — дополнительные возможности лямбд и потоков
- `chapter06` — Optional
- `chapter07` — работа с файлами
- `chapter08` — Date and Time API
- `chapter09` — параллельное программирование
- `chapter10` — Java 9

Каждый рецепт реализуется в отдельном классе или группе классов.

**Пример:** `Recipe0101LambdaExpressions.java` — рецепт 1.1 из первой главы.

Пакеты создаются постепенно, по мере изучения материала.

## 🎯 Мой подход к обучению

1. Изучить теоретический материал из книги.
2. Самостоятельно написать пример в IntelliJ IDEA.
3. Запустить программу и проверить результат.
4. Поэкспериментировать с кодом.
5. Разобраться в непонятных моментах.
6. Сохранить результат отдельным Git-коммитом.

**Главный принцип: понимать код, а не просто копировать его.**

## 🌿 Git Workflow

Для каждой главы создаётся отдельная ветка от `master`.

Примеры названий:

- `chapter/01-basics`
- `chapter/02-functions`
- `chapter/03-streams`

По мере прохождения главы создаются коммиты с реализациями отдельных рецептов.

После завершения главы изменения объединяются с `master` через GitHub Pull Request.

## 🚀 Как запустить проект

**Требования:** JDK 17 и IntelliJ IDEA с поддержкой Gradle.

1. Клонировать репозиторий:

   `git clone https://github.com/NickRayman/modern-java-recipes.git`

2. Открыть папку проекта в IntelliJ IDEA.
3. Дождаться синхронизации Gradle.
4. Открыть нужный Java-класс и запустить его метод `main()`.

Для проверки сборки на Windows можно выполнить:

`.\gradlew.bat build`
